# Gusanos al agujero

Juego de gusanos para Android. Al subir este proyecto a GitHub, se construye el APK solo.

1. Crea un repositorio nuevo en GitHub y sube todos estos archivos (incluida la carpeta .github).
2. Entra a la pestaña Actions y espera a que termine "Construir APK" (unos 5 a 10 minutos).
3. Ve a Releases (columna derecha del repositorio) y descarga gusanos-al-agujero.apk.
4. En el teléfono, abre el APK y permite instalar apps de origen desconocido.
